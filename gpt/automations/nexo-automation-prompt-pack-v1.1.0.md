# NEXO — cinco prompts preparados, versão 1.1.0

Este pacote não foi aplicado às tarefas e não ativa o mandato. O arquivo JSON contém somente os cinco prompts, seus hashes e candidatos a fragmentos operacionais. Não contém agenda, modelo ou estado para sobrescrever configurações atuais. A versão 1.0.0 permanece como histórico da auditoria de 04/10; seus IDs e alegações datadas não provam a configuração atual.

A instalação humana posterior relê o inventário vivo, reconcilia cada função, salva somente o prompt e confirma a leitura posterior. Os IDs observados abaixo são pistas de reconciliação. Preservar mudanças concorrentes e todos os demais campos. O núcleo fixo permanece no prompt salvo; um fragmento válido da Tower só substitui o fallback operacional. Os fragmentos deste pacote são candidatos locais, sem aprovação canônica.

O procedimento e a reversão estão em `docs/nexo-autonomy-preparation.md`. O mandato permanece desativado enquanto a aprovação autenticada, o recibo de ativação e o readback do CONTROL não estiverem comprovados.
