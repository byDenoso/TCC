# NEXO Lean-MIN Design

Approved operational direction: reduce NEXO execution admission to three legitimate blocker classes only: `SCIENTIFIC_DEFINITION_MISSING`, `AUTHORIZATION_MISSING`, and `IRREVERSIBLE_CONFLICT`.

The NDMK/TOWER_V06 remains the only operational truth owner. No second kernel, router, memory plane, scheduler, or principal automation is introduced.

Operational metadata such as evidence IDs, recipe IDs, capability manifest copies, queue projection membership, HOT_SET visibility, validation refs, runtime flags, and resource-lock flags must be derived, repaired, or validated without becoming existence gates whenever doing so cannot alter frozen science.

Canonical operational states converge toward READY, RUNNING, DONE, BLOCKED. CHECKPOINT becomes recovery metadata and never consumes compute while idle.

The four principal automations coordinate only through canonical state, event cursors, material deltas, result references, persistence and readback. A second pulse with no material delta is a NO-OP.
